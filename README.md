# World Happiness Report Analysis

As a part of an academic submission, this project aims to explore the World Happiness Report dataset, perform various analyses, and test hypotheses about the factors affecting happiness in different countries. The analysis focuses on factors like GDP per capita, family support, health, and more to understand their correlation with happiness scores.

## Project Overview:
In this project, we performed exploratory data analysis (EDA) and hypothesis testing to identify patterns and relationships within the data. Key findings include:

1. **Exploration of relationships** between happiness scores and economic factors such as GDP per capita, family support, and health.
2. **Hypothesis Testing** to check if wealthier countries are happier and if family support correlates with higher happiness.
3. **Correlation analysis** to identify factors that have the most influence on happiness.
4. **Visualizations** to better understand the relationships and distributions of the data.

## Requirements:
To run this project locally, you'll need the following Python libraries:

- pandas
- numpy
- seaborn
- matplotlib
- scipy
- statsmodels


## Dataset:
The datasets used in this project are from Kaggle. The specific data files used for analysis can be found in the `datasets/` folder.

## Files in the Repository:
- `world_happiness_analysis.ipynb`: The Jupyter notebook containing the analysis, visualizations, and results of the hypothesis tests.
- `datasets/`: Folder containing the data files (e.g., `2022.csv`).
- `README.md`: Markdown file containing project description.
- `requirements.txt`: Text file containing all the required modules and libraries.

## Steps to Reproduce:
1. Clone this repository to your local machine using:
```
git clone https://github.com/harleenkaur13/World-Happiness-Report-Analysis.git
```
2. Navigate to the project directory:
```
cd World-Happiness-Report-Analysis
```
3. Install the necessary dependencies:
```
pip install -r requirements.txt
```
4. Open the Jupyter notebook (`world_happiness_analysis.ipynb`) and run the cells to see the analysis and results.
